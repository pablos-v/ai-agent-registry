# Политика: гигиена секретов

**Секрет — пароль, токен, API-ключ, приватный ключ, строка подключения с паролем —
никогда не попадает в переписку с моделью.** Всё, что попало в контекст, считается
скомпрометированным и подлежит ротации: переписка уходит в API и остаётся в логах на диске.

## Запреты для агента

- Не читать файлы кредов: `.env`, `*.properties` с паролями, `*.pfx`, приватные ключи.
- Не выполнять дамп окружения (`env`, `printenv`, `declare -x`, `Get-ChildItem Env:`) —
  одна такая команда выносит в контекст все ключи разом.
- Не подставлять пароль в командную строку (`mysql -pПАРОЛЬ`, `sshpass -p`,
  `curl user:pass@host`) — он виден в списке процессов и в логах.
- При выводе любой конфигурации — вырезать значения по маске `pass|pswd|token|apikey|secret`
  и писать `<вырезано>`.
- Если секрет всё же оказался в контексте — сказать об этом прямо и внести в список
  на ротацию, а не продолжать молча.

## Как секрет попадает в операцию

1. Секрет хранится в менеджере паролей.
2. Оттуда — в файл кредов с правами `600` или в переменную окружения.
3. Агенту сообщается **только имя** переменной или путь к файлу, никогда значение.
4. Команда собирается так, чтобы значение подставил шелл на исполнении:
   `mysql --defaults-extra-file=<файл>`, `PGPASSFILE=<файл> psql ...`.

## Уроки, из которых выросли правила

- **Фильтр ставится всегда, а не когда ждёшь секрет.** Запрос «покажи записи конфигурации
  с включёнными плагинами» выглядел безобидно — в выдаче рядом с флагом оказался пароль
  сервисной учётки. Фильтра не было, потому что «здесь секретов быть не должно».
- **Выбрасывать строку целиком, а не маскировать хвост.** Регулярное выражение с жадным
  `.*` цепляется к последнему совпадению и молча пропускает предыдущие; надёжнее
  отбрасывать строку по маске.
- **Проверять фактический вывод глазами.** Частично обрезанный вывод выглядит как успешно
  замаскированный.
- **Уникальные имена временных файлов.** Фиксированное `/tmp/q.sql` при работе под разными
  учётными записями однажды достаётся другому владельцу — загрузка молча падает,
  а выполняется оставшийся там чужой файл.

## Правило одной строкой

**Если для решения задачи агенту нужно знать значение пароля — задача поставлена неправильно.**
